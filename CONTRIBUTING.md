# Contributing

Welcome contributors working on documentation, glossary, translations, language ports, fixtures, validators, accessibility, and navigation.

Before contributing: read the target project's README, START-HERE, and AGENTS files; check its license, security policy, maturity, and contribution rules; confirm the change belongs there.

Every contribution should state purpose, audience, affected projects, provenance, tests/review performed, limitations, and license compatibility. Keep pull requests focused. Avoid bulk-generated files without reproducible generation and human review.

Forks are welcome where the license permits. Preserve license/copyright/NOTICE material, identify modifications, link upstream, and do not imply official status or endorsement. Never put secrets, personal data, or live customer payloads in fixtures. Use the affected repository's responsible disclosure process for vulnerabilities.
