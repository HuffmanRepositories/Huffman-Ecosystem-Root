# Start Here — A Guided Tour

You do not need to read every repository to participate.

## Five-minute route
1. Read the root README.
2. Scan PROJECT-CATALOG.md.
3. Pick one project that matches your question.
4. Read that project's README, START-HERE.md, and AGENTS.md.
