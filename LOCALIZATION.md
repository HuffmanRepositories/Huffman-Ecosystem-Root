# Human-Language Localization

English is the canonical source language unless a project explicitly changes that policy. First-wave priority locales: Spanish (es), Simplified Chinese (zh-Hans), Hindi (hi), Arabic (ar), French (fr), Portuguese (pt), Bengali (bn), Russian (ru), Japanese (ja), German (de), Urdu (ur), and Indonesian (id). This is a practical initial priority list, not a definitive ranking.

Start by translating README, START-HERE, safety guidance, and glossary—not every file. Preserve project names, code identifiers, schema keys, protocol tokens, and URLs. Preserve warnings and limitations. Use UTF-8 and check right-to-left layout for Arabic and Urdu. Machine-assisted drafts must be marked unreviewed until a competent human reviewer verifies technical meaning.

Suggested statuses: not-started, draft, needs-review, reviewed, stale. Each locale folder should record source revision, translators, reviewers, terminology decisions, and unresolved gaps. New languages are welcome through pull requests.
